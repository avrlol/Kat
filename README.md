# Студент — расписание пар и заданий

Мобильное приложение (Android, Kotlin) для курсового проекта по МДК 01.03
«Разработка мобильных приложений». Тема: **«Студент»** — расписание пар с
домашними заданиями и напоминаниями о дедлайнах.

## Стек
- Kotlin, единая Activity + Navigation Component (5 экранов через BottomNavigationView)
- Архитектура: **MVVM** (ViewModel + LiveData)
- База данных: **Room** (SQLite)
- Графики: **MPAndroidChart**
- Асинхронность: Kotlin Coroutines

## Экраны
1. **Сегодня** — пары и задания на текущий день
2. **Расписание** — пары по дням недели
3. **Задания** — список заданий, CRUD, поиск/фильтры/сортировка
4. **Статистика** — графики успеваемости по предметам
5. **Настройки** — тема, уведомления, единицы измерения

## «Изюминка»
Push-уведомления о приближающихся дедлайнах заданий (WorkManager/AlarmManager).

## Структура пакетов
```
com.student.scheduler
├── model            — data-классы сущностей
├── data
│   ├── database     — Room: Entity, DAO, Database
│   └── repository   — репозитории, единая точка доступа к данным
├── ui               — Fragment'ы по экранам (home, schedule, tasks, statistics, settings)
├── viewmodel        — ViewModel'и экранов
├── adapters         — RecyclerView.Adapter
└── utils            — вспомогательные классы
```

## Как открыть
1. Открыть папку проекта в Android Studio (Koala/Ladybug или новее).
2. Дождаться Gradle Sync (при первом открытии Android Studio сама
   догенерирует `gradle-wrapper.jar`).
3. Запустить на эмуляторе/устройстве (minSdk 24).
